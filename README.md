# DataWeave Lab — Questions, Answers & 10,000+ Examples

A beginner-friendly, practical MuleSoft DataWeave learning library built around one simple idea: **see the input, understand the transformation, and verify the output**.

## ✨ What this project aims to provide

- 10,000+ practical DataWeave examples
- Beginner → Intermediate → Advanced progression
- Input → DataWeave → Expected Output → Explanation
- JSON, XML and CSV transformations
- Arrays, objects, strings, dates, numbers and functions
- Real-world MuleSoft integration scenarios
- Interview-focused questions
- Challenge/practice examples
- Searchable structured dataset for future tools and AI assistants

## 🌐 Homepage

Open `index.html` directly or enable **GitHub Pages** for the repository to publish the modern learning homepage.

## 📖 Example format

Every example should make the transformation easy to understand:

```text
Question
↓
Input
↓
DataWeave
↓
Expected Output
↓
Plain-English Explanation
↓
Common Mistakes / Edge Cases
```

## 🧪 Quality standard

Examples should be validated for syntax, input/output consistency, explanation accuracy and duplicates before being counted as completed examples. Runtime-specific behavior should be checked against the DataWeave version being documented.

## 🤝 Contributions

New examples are welcome. Keep examples focused, realistic and easy for a beginner to follow. Prefer small transformations over unnecessarily complicated code.
