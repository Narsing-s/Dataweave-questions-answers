# Real DataWeave Q&A Bank

This folder contains curated, hand-written DataWeave 2.x practice questions. Unlike mechanically generated records, each example is designed around a distinct transformation problem.

## Format

Every question follows:

**Question → Input → DataWeave → Output → Explanation → Common mistake → Interview tip**

## Levels

- `EASY.md` — fundamentals, selectors, simple functions, strings, arrays, objects, conditions and defaults.
- `MEDIUM.md` — nested transformations, grouping, deduplication, object operations, dates and practical mappings.
- `ADVANCED.md` — production-style reshaping, dynamic keys, aggregation, XML, CSV, error-oriented patterns and interview challenges.

The examples are aligned with documented DataWeave concepts such as `map`, `filter`, `groupBy`, `reduce`, `mapObject`, `filterObject` and `pluck`. Always execute examples in the DataWeave/Mule runtime used by your project before production use.
