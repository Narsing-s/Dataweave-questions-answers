# Changelog

All notable changes to this project are documented here.

## [1.2.0] - 2026-09-17

### Added

- Community contribution workflow using GitHub Discussions, Issues, and Pull Requests.
- Structured Discussion templates for question ideas and quality reports.
- Contributor roadmap and support documentation.
- Public-launch and contributor guidance for growing the project community.
- Release/package workflow for reproducible ZIP and SHA-256 distribution artifacts.
- GitHub Packages npm publishing configuration for `@narsing-s/dataweave-lab`.
- Version metadata aligned to `1.2.0`.

### Verification

- The repository contains 10,000 structured practice records with sequential IDs.
- Static validation and quality-audit workflows remain in place.
- Runtime execution of every DataWeave transformation is not claimed by static validation.

## [1.0.0] - 2026-09-16

### Added

- 10,000-record DataWeave practice bank.
- Easy, Medium, and Advanced learning paths.
- Interactive Explorer/Lab experience.
- Search, topic filtering, pagination, random practice, copy, solution reveal, challenge mode, and shareable question routing.
- Static dataset validation and generation workflows.
- GitHub Pages deployment workflow.
- Release/package workflow with ZIP and SHA-256 checksum generation.
- Release readiness and package documentation.
- Project version metadata.

### Verification

- Static dataset/schema checks are automated.
- Full runtime execution of every DataWeave transformation is intentionally not claimed by the static validator.
- Release packaging is reproducible through GitHub Actions.

Future changes should be added to `Unreleased` before the next version is tagged.
