10 Solved Practice Questions

1. Transform an array of employee records

Question: Convert employee records into an API-friendly structure containing the employee name and birth year.

INPUT
[{"name":"John","age":25},{"name":"Alice","age":30}]
DATAWEAVE
%dw 2.0
output application/json
---
payload map (employee) -> {
  fullName: employee.name,
  birthYear: now().year - employee.age
}
EXPECTED OUTPUT
[{"fullName":"John","birthYear":2001},{"fullName":"Alice","birthYear":1996}]

Learn: map transforms every item in an array. Use mapObject for object entries.

2. Filter records before transforming them

Question: Return only active employees and expose their names and departments.

INPUT
[{"name":"Ravi","active":true,"department":"IT"},{"name":"Meena","active":false,"department":"HR"},{"name":"Arun","active":true,"department":"Finance"}]
DATAWEAVE
%dw 2.0
output application/json
---
payload
  filter ((employee) -> employee.active)
  map ((employee) -> {
    name: employee.name,
    department: employee.department
  })
EXPECTED OUTPUT
[{"name":"Ravi","department":"IT"},{"name":"Arun","department":"Finance"}]

Pattern: filter first → transform second.

3. Remove duplicate business records

Question: Keep one customer record for each customer ID.

INPUT
[{"id":101,"name":"Asha"},{"id":102,"name":"Vijay"},{"id":101,"name":"Asha"}]
DATAWEAVE
%dw 2.0
output application/json
---
payload distinctBy $.id
EXPECTED OUTPUT
[{"id":101,"name":"Asha"},{"id":102,"name":"Vijay"}]

Learn: Identify the business key before deciding what constitutes a duplicate.

4. Calculate a total with reduce

INPUT
[120,50,75,200]
DATAWEAVE
%dw 2.0
output application/json
---
payload reduce ((item, total = 0) -> total + item)
EXPECTED OUTPUT
445

Learn: Use reduce when multiple values must become one accumulated result.

5. Group transactions by department

INPUT
[{"name":"Asha","department":"IT"},{"name":"Ravi","department":"HR"},{"name":"Kiran","department":"IT"}]
DATAWEAVE
%dw 2.0
output application/json
---
payload groupBy $.department
EXPECTED OUTPUT
{"IT":[{"name":"Asha","department":"IT"},{"name":"Kiran","department":"IT"}],"HR":[{"name":"Ravi","department":"HR"}]}

6. Work with dates

INPUT
"2026-09-22"
DATAWEAVE
%dw 2.0
output application/json
---
(payload as Date) as String {format: "dd-MMM-yyyy"}
EXPECTED OUTPUT
"22-Sep-2026"

Learn: Parse as Date, then format as a string.

7. Handle missing values safely

INPUT
{"name":"Asha"}
DATAWEAVE
%dw 2.0
output application/json
---
{
  name: payload.name,
  city: payload.city default "Unknown"
}
EXPECTED OUTPUT
{"name":"Asha","city":"Unknown"}

8. Transform nested order data

INPUT
{"orders":[{"id":1001,"items":[{"name":"Laptop","quantity":1},{"name":"Mouse","quantity":2}]}]}
DATAWEAVE
%dw 2.0
output application/json
---
payload.orders map (order) -> {
  orderId: order.id,
  products: order.items map $.name
}
EXPECTED OUTPUT
[{"orderId":1001,"products":["Laptop","Mouse"]}]

Think level by level: orders array → order object → items array → item field.

9. Calculate an API percentage

INPUT
{"successful":92,"total":100}
DATAWEAVE
%dw 2.0
output application/json
---
{
  successPercentage: (payload.successful / payload.total) * 100
}
EXPECTED OUTPUT
{"successPercentage":92}

In production, explicitly decide what should happen when the denominator is zero or missing.

10. Build a reusable DataWeave function

INPUT
[{"name":"  asha "},{"name":" ravi"}]
DATAWEAVE
%dw 2.0
import * from dw::core::Strings
output application/json

fun normalizeName(value) =
  upper(trim(value))
---
payload map (customer) -> {
  name: normalizeName(customer.name)
}
EXPECTED OUTPUT
[{"name":"ASHA"},{"name":"RAVI"}]

Learn: Reusable functions keep transformations readable and business rules easier to test.

How to practice

  1. Read only the question and input.
  2. Predict the output.
  3. Write your own DataWeave.
  4. Run it against your Mule/DataWeave runtime.
  5. Compare with the expected output.
  6. Study the explanation and common mistake.
  7. Try an edge case.
  8. Rewrite the solution another valid way.
  9. Explain the solution without looking at the answer.

Easy → Medium → Advanced

🟢 Easy

Fundamentals, strings, numbers, arrays, objects, basic map/filter, dates, DateTime, null handling, default and selectors.

🟡 Medium

Nested collections, groupBy, orderBy, distinctBy, reduce, flatten, flatMap, date calculations, DateTime transformations, functions and practical API transformations.

🔴 Advanced

Complex nested transformations, dynamic objects, reusable functions, advanced filtering/mapping, error handling, XML/JSON/CSV combinations, performance considerations and difficult interview scenarios.

Interview preparation

Use this loop: learn the function → solve a basic problem → solve a scenario → predict output → explain trade-offs → handle an edge case.
