# Support

Use the right channel so questions reach the right people and do not get lost.

## GitHub Discussions

Use Discussions for:

- DataWeave learning questions
- conceptual explanations
- interview preparation conversations
- ideas for new questions
- advanced transformation challenges
- community feedback
- project direction

If you are unsure whether a question already exists, ask in Discussions first.

## GitHub Issues

Use an Issue for:

- incorrect answers or expected output
- reproducible dataset problems
- broken learning-site behavior
- scoped feature requests
- documentation bugs

## Pull Requests

Use a Pull Request for a concrete fix or improvement. Read `CONTRIBUTING.md` before submitting.

## Security

Do not post credentials, tokens, customer data, private banking information, or other sensitive material in Discussions, Issues, or Pull Requests. Follow the repository security policy for vulnerability reports.
