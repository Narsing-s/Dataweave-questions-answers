# Security Policy

## Scope

This project is a static learning resource and practice website. It should not contain production credentials, customer records, private API keys, or other sensitive information.

## Reporting a security issue

Please do not publish secrets or exploitable details in a public issue. Contact the repository owner through the private contact mechanism available from the repository owner profile and provide enough information to reproduce the issue safely.

## Sensitive-data rule

Never commit:

- passwords or access tokens;
- cloud credentials;
- private keys or certificates;
- real customer/account information;
- production database connection strings;
- proprietary company data.

Use synthetic examples in all DataWeave questions.
