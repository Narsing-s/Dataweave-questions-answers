# Practice Mode

## Goal

Practice mode changes passive reading into active problem solving.

### Recommended sequence

1. Select a level.
2. Choose a topic.
3. Open a question.
4. Read only the input and expected output.
5. Write your own DataWeave.
6. Reveal the reference solution.
7. Compare structure, types and edge-case handling.
8. Repeat with a different question.

## Challenge checklist

Before revealing the answer, check:

- Did I identify the input type correctly?
- Did I choose the correct iterator/object function?
- Did I handle null and empty values?
- Did I preserve the required output shape?
- Did I consider duplicate records?
- Is the expression deterministic?
- Is the transformation readable?

## Interview practice

Use the `REAL-QA` material for authored interview questions and the 10,000 bank for high-volume repetition. Do not treat generated examples as proof of runtime compatibility until they are executed against the target runtime.

## Local progress

Browser-side progress can safely be treated as a convenience feature. It should never be used as an authoritative score or certification record because browser storage can be cleared or modified by the user.
