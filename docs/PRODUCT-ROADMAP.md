# DataWeave Lab Product Roadmap

## Current foundation

- 10,000 structured practice records
- Easy / Medium / Advanced learning paths
- Search, filtering, pagination and challenge mode
- Shareable question URLs
- Static validation and GitHub Actions
- Release packaging and checksums
- Official-resource guide
- Open-source contribution and security guidance

## Next product upgrades

### Learning

- Progress tracking stored locally in the browser
- Bookmarks and a personal practice queue
- Incorrect-answer review mode
- Topic completion indicators
- Spaced-review mode
- Interview session timer
- Printable question sheets

### DataWeave practice

- Input/output editor with syntax highlighting
- Run/verify integration through an explicitly configured DataWeave runtime
- Expected-output comparison with readable diffs
- Null/empty/error test cases per question
- More XML, CSV, YAML, NDJSON and multipart scenarios
- Mule event examples: payload, attributes and vars

### Content quality

- Stable topic taxonomy
- Duplicate/concept-similarity detection
- Runtime-tested curated examples
- Version tags for DataWeave/Mule compatibility
- Coverage report by topic and difficulty

### Product engineering

- Automated accessibility checks
- Lighthouse/performance checks
- Browser smoke tests for every release
- Better SEO metadata and social preview cards
- Changelog-driven releases
- Dependabot or equivalent dependency monitoring when dependencies are introduced

## Product principle

The site should remain useful without an account or backend. Authentication is not required for learning. Any future user account feature should be optional and should not block access to the public learning library.
