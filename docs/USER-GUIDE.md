# DataWeave Lab User Guide

## Start learning

Open `index.html` and enter the Explorer. Choose a difficulty, topic, or search term.

## Practice a question

1. Read the problem and input.
2. Write your own DataWeave transformation.
3. Reveal the reference solution.
4. Compare the expected output with your result.
5. Read the explanation and edge cases.
6. Use challenge mode to practice without immediately relying on the answer.

## Search and filtering

Search can be used for question text, DataWeave code, inputs, outputs, and explanations. Difficulty and topic filters can be combined with search.

## Share a question

Use the question's share action to create a URL containing its routing information. A shared URL can reopen the corresponding practice context.

## Learning order

Begin with syntax, selectors, objects, arrays, strings, numbers, conditions, `map`, and `filter`. Continue with `reduce`, `groupBy`, `mapObject`, `pluck`, dates, type conversion, and format transformations. Finish with nested transformations, dynamic keys, enrichment, error handling, performance, and real-world API scenarios.

## Important verification note

The repository's structural validator checks dataset quality but does not execute every DataWeave script. For project work, validate important transformations against the Mule/DataWeave runtime version used by the target application.
