This project is an independent learning resource. Use the official MuleSoft documentation and tools below as the authoritative references for language behavior, runtime compatibility, and platform features.

## Official tooling

- [DataWeave CLI](https://github.com/mulesoft/data-weave-cli) — official MuleSoft open-source CLI for working with structured data and DataWeave.
- [MuleSoft DataWeave Playground](https://dataweave.mulesoft.com/) — interactive environment for trying transformations.

## How this repository should be used

1. Learn the concept here.
2. Open the official documentation when syntax or runtime behavior matters.
3. Run the transformation against the DataWeave/Mule runtime used by your project.
4. Add tests for important production transformations.

The repository intentionally does not claim that generated examples are individually certified against every MuleSoft runtime version.
